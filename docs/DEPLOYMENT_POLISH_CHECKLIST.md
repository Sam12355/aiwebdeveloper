# Final Live Deployment Polishing Checklist

## Before upload
- Replace demo phone/email text
- Replace placeholder URLs
- Confirm logo and branding
- Compress images if needed
- Confirm theme images load
- Confirm all JS/CSS paths
- Confirm favicon

## Server
- Enable SSL
- Force HTTPS
- Set correct PHP version
- Create database
- Import schema
- Update backend/config.php
- Protect backend files
- Test file upload permissions

## SEO
- Add production meta titles
- Add meta descriptions
- Add Open Graph images
- Create sitemap.xml
- Create robots.txt
- Add Google Analytics / Tag Manager if required

## Security
- Backend sessions enabled
- Admin password changed
- Disable demo admin login
- Form validation server side
- File upload validation server side
- Payment webhook signature validation

## Launch
- Test full customer journey
- Test admin journey
- Test payment sandbox
- Test email notification
- Test mobile view
- Test live website flow
